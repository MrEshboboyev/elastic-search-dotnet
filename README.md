## 🚀 Quick Start

1. Clone this bad boy:
   ```bash
   git clone https://github.com/MrEshboboyev/elastic-search-dotnet.git
   ```
2. Install dependencies:
   ```bash
   dotnet restore
   ```
3. Run it and feel the power:
   ```bash
   dotnet run
   ```
